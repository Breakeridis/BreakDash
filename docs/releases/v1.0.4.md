# BreakDash v1.0.4

Encrypted temporary reports, ready to share without server setup.

## Send a diagnostic report

1. **About → Report a problem → Preview report**.
2. Review your note and captured system details.
3. Tap **Upload for 3 hours**.
4. **Copy share link** and paste the complete link in your support chat before it expires.

Each report is encrypted on the device using a fresh AES-256-GCM key before upload to Uguu. The decryption key stays in the share link's fragment; it is absent from the file sent to the host. Anyone with the complete link can read the report, so share it only with the intended recipient. Uguu advertises a three-hour file lifetime.

Preview/redaction remain in place. There are no automatic uploads or retries. The optional **Send to my server** route still supports the existing owner-controlled receiver and RSA public key.

## Downloads

- **32-bit ARM (armeabi-v7a):** `BreakDash-v1.0.4-armeabi-v7a.apk`.
- **64-bit ARM (arm64-v8a):** `BreakDash-v1.0.4-arm64-v8a.apk`.

Use **Updates → Check again**, or install the matching signed APK over the existing release to preserve preferences.

Built and checked on GitHub Actions: Android builds/lint, JVM encryption tests, Java-to-Node decryption, receiver tests, ABI/signature verification, and an opt-in live Uguu probe using synthetic data only. No real device report is uploaded during verification, and nothing is compiled or run locally. Physical-device UI/network behavior still needs checking.
