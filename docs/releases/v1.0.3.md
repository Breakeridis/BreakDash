# BreakDash v1.0.3

Direction-of-travel navigation with a tilted driving view.

## Navigation camera

- After the brief route overview, navigation uses a **45° tilted perspective** and a closer road zoom.
- The camera follows the car's GPS travel direction, with the vehicle slightly below center to show more road ahead.
- A directional vehicle arrow replaces the plain dot once GPS establishes a reliable moving course. Turning the device does not turn the map.
- Camera movements are smoothed between GPS updates. Stops, slow GPS drift, and unreliable bearing measurements keep the last reliable direction steady.
- Map gestures still allow exploration. Tap **◎ Recenter** to restore the driving view; stop navigation to return to the flat dashboard map.
- Keeps the existing 20 FPS cap and visible-dashboard GPS lifecycle; no additional orientation sensor or background tracking service.

## Download naming

- Downloads are described by architecture throughout the documentation and release pages.
- **32-bit ARM (armeabi-v7a):** `BreakDash-v1.0.3-armeabi-v7a.apk` — the Junsun / Nowada head unit.
- **64-bit ARM (arm64-v8a):** `BreakDash-v1.0.3-arm64-v8a.apk` — compatible 64-bit ARM devices.

Install the matching APK over the existing signed release, or open **Updates → Check again**. The production package and signing key are unchanged, preserving preferences.

Builds, lint, JVM tests (including stopped/invalid GPS heading cases), receiver tests, ABI checks, and signature verification run on GitHub Actions. Driving-view fit, turn transitions, and performance still need checking on a physical device. Nothing was compiled or run locally.
