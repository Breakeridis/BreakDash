# BreakDash v1.0.11

A clearer navigation-first cockpit, with distinct navigation/radio colours and stronger day/night contrast.

- New white/day and near-black/night palettes, bold readable labels, solid control surfaces and clear outlines. Blue identifies navigation and primary actions; amber identifies radio; green identifies confirmed active states.
- Larger next-turn distance/instruction and destination detail in a top map banner, with explicit arrival, off-route and GPS-loss states. Search and Recenter now have visible labels. Pin Navigate/Clear controls remain separate.
- Larger speed, radio metadata, presets, app labels and settings text. Selected presets and tabs have filled backgrounds and explicit selection states; switches retain readable On/Off labels and contrasting thumbs.
- Removes the greeting, slogans and repeated hold-to-configure hints. The four app shortcuts and Settings/Updates/About remain in their established positions. The circular map keeps its full size.
- Applies matching colours to map routes, vehicle markers, pins and native inputs/dialogs. The manual theme choice and other preferences are retained.
- Unavailable update downloads remain hidden, and update source stays compact. Radio integration, GPS frequency, map animation timing and route calculations are unchanged.

Install **BreakDash-v1.0.11-armeabi-v7a.apk** on the head unit, or **BreakDash-v1.0.11-arm64-v8a.apk** on compatible 64-bit devices. Signed updates preserve preferences. Head units still blocked by a pre-v1.0.8 **Missing APK signature** error need one manual installation over the app.

GitHub Actions verifies essential-text/control contrast and guidance presentation, alongside existing tests, Android lint/builds and ABI/signature checks. No local app execution, builds or tests are run. Day/night glare, long text, larger fonts, touch targets and perceived readability still need physical-device validation. See [readability design and checks](../cockpit-readability.md).
