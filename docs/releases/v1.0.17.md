# BreakDash v1.0.17

Adds the first explicit factory Bluetooth status connection, using the SDK entry points captured on the head unit.

- **Check factory Bluetooth status** returns to the dashboard for a session lasting up to eight seconds. It obtains the service intent from the trusted installed SDK, resolves and verifies the factory target, and owns the Android binding and cleanup.
- Checks the returned Bluetooth interface and uses the factory's generated proxy to read only observed boolean power/profile states and numeric status/feature values. It implements no undocumented Binder or Parcelable layout and registers no phonebook callbacks.
- Saves clear SDK-initialization, resolution, binding and reading stages, with fixed outcomes and capture version. Opaque extras, exception messages, PINs, contacts and device identities are excluded. Inspection remains separately available without executing SDK code.
- Cancels when the dashboard is hidden, releases the binding, discards late results and prevents repeated workers accumulating behind a stalled vendor call. No background polling or automatic retry is added.

After updating through **Updates → Check again**, open **Settings → Bluetooth → Open Bluetooth → Diagnostics → Check factory Bluetooth status**. Stay on the dashboard until the saved-result message, then reopen **Diagnostics** and **Send feedback**. No need to repeat the SDK inspection. The check does not need local ADB or Android DUMP permission.

Success confirms access to the factory Bluetooth service. It does not yet repair Android BLE error 3, connect the KW906 or provide live OBD readings. No pairing, reset, calls, music controls or vehicle commands are issued.

GitHub Actions runs getter-allowlist/privacy, cancellation/deadline/cleanup regressions, existing checks, lint, both ARM APK builds and signature verification. Use the **armeabi-v7a** APK on the 32-bit head unit. Actual SDK initialization, service access and coexistence still require the head-unit check above; some synchronous vendor calls cannot be forcibly interrupted.
