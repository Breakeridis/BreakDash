# BreakDash v1.0.0

First signed release of BreakDash, a lightweight native Android cockpit for the Junsun / Nowada K2401 head unit, with a separate build for 64-bit ARM phones.

## Downloads

- **Head unit:** `BreakDash-v1.0.0-armeabi-v7a.apk` — Android 10/API 29 or newer, 32-bit ARM.
- **64-bit ARM (arm64-v8a):** `BreakDash-v1.0.0-arm64-v8a.apk`.

Download the APK directly and open it through Android's installer. Each APK includes only its own native architecture. Matching `.sha256` files are included.

## Included

- Landscape cockpit with clock, day/night themes, GPS speed and heading, and a circular vector map.
- In-map pan, pinch/double-tap zoom, rotation, and Recenter to resume heading-up GPS tracking.
- Long-press destination pins with Navigate/Clear actions and in-app route guidance.
- NWD hardware radio controls, live station state, RDS text, and six saved presets.
- Searchable app drawer, pinned favorites, and configurable dashcam, projection, navigation, and music shortcuts.
- On-demand hardware monitoring, Google package controls through authorized local ADB/root, and Aurora Store installation.
- GitHub release checks and signed APK updates for the device's architecture.
- Diagnostic previews and optional encrypted uploads to an owner-configured server, without GitHub issue storage.

## First installation

The release uses `com.breakdash.launcher`; earlier development APKs use `com.breakdash.launcher.debug`. They can coexist, but settings do not transfer automatically. After configuring the release, you can remove the development app and choose the release as your Home app.

Online maps start disabled. Enable them under **Settings → Connect online maps**, then allow precise location for GPS. NWD radio and other vendor integrations require the head unit and are unavailable on a normal phone. Cloud uploads remain disabled until an HTTPS endpoint and public key are configured.

## Validation and limits

Built on GitHub Actions with lint, JVM tests, optimized release builds, native-architecture checks, and APK signature verification. No local application builds or execution were used.

Head-unit firmware behavior and performance still need physical-device validation. Routes require internet; guidance is visual, with no voice instructions, offline routing, or automatic off-route recalculation. This release targets Android 10/API 29 and later.
