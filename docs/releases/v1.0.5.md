# BreakDash v1.0.5

Encrypted feedback to a fixed ntfy inbox, with no link copying.

## Send feedback

1. **About → Report a problem → Preview report**.
2. Review the captured system details and optional note.
3. Tap **Send feedback**.
4. Ask to check your latest feedback within three hours.

The topic and recipient stay fixed across reports. Each report still uses a fresh AES-256-GCM key and nonce; RSA-OAEP-SHA256 wraps its key for the recipient. Only the public recipient key is in the app. The private key remains protected in the recipient workspace, outside the APK, repository, and GitHub Actions.

The fixed inbox needs no account or server deployment. Its public topic is transport, not proof of sender identity. Reports are treated as untrusted diagnostics. **Temporary link** retains Uguu sharing, and **My server** retains the optional owner receiver. Uploads remain explicit and limited to the previewed capture.

## Downloads

- **32-bit ARM (armeabi-v7a):** `BreakDash-v1.0.5-armeabi-v7a.apk`.
- **64-bit ARM (arm64-v8a):** `BreakDash-v1.0.5-arm64-v8a.apk`.

Use **Updates → Check again**, or install the matching signed APK over the current release to retain preferences.

GitHub Actions runs builds/lint, JVM tests, Java-to-Node recipient encryption checks, receiver tests, native ABI and signature checks, plus an opt-in live ntfy probe using synthetic data and a disposable topic/key. No real device report or production private key is used in CI. Physical-device interaction/network behavior still needs checking; nothing is compiled or tested locally.
