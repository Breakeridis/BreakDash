# BreakDash v1.0.1

More map, less unused space.

## Layout fixes

- Removed the outer cockpit padding, column gutters, and fixed-aspect letterboxing on wider phone screens.
- Enlarged the center map to the largest square between usable side columns. On the reference 1280×720 head unit, its region now occupies 720×720.
- Moved search and the **◎ Recenter** control into floating buttons at the top right of the map.
- Replaced the tall speed panel and full-width GPS row with compact overlays near the map's lower edge.
- Moved pinned destinations and route guidance into a compact floating banner. It appears when needed and never shrinks the map.
- Adjusted route-overview framing to keep destination pins clear of the new navigation overlay.
- Kept map gestures and long-press destination selection, with separate touch handling for overlay controls.
- Reformatted radio presets onto two lines for the narrower side column.

## Downloads and updating

- **Head unit:** `BreakDash-v1.0.1-armeabi-v7a.apk`.
- **64-bit ARM (arm64-v8a):** `BreakDash-v1.0.1-arm64-v8a.apk`.

Both APKs use the same package and signing certificate as v1.0.0. Update through **About → Check for updates** or install the matching APK directly over the existing release. Preferences and configured apps are retained; no uninstall is needed when upgrading the signed release.

Built, linted, tested, signed, and verified on GitHub Actions. Physical display fit and touch interaction still need checking on the head unit or phone; no local app execution or compilation was used.
