# BreakDash v1.0.7

Clearer settings and a quieter Updates page for the head unit.

- Apps shows Aurora Store's installed status with a green presence indicator and an Open/Install action. This indicator does not disable or uninstall Aurora.
- Google Services Framework, Play Services and Play Store have labeled switches directly in Apps. Green means confirmed On; Off, hidden and missing states are written out. Pending or failed changes retain the actual package state.
- Google service tools holds the bulk switch, Local ADB, action details and copyable commands.
- Night mode and online maps use the same large switch rows. Connecting maps still requires the existing consent screen.
- Updates hides Download & install until a newer compatible release is available, and while checking or after a failed check. What's new only appears once a release has been found.
- Update source is a compact repository link instead of a full-size button. APK validation and installer confirmation remain in place.

Download the **32-bit ARM APK (armeabi-v7a)** for the K2401 head unit, or **64-bit ARM APK (arm64-v8a)** for compatible 64-bit devices. Install over the current signed release to preserve preferences.

GitHub Actions handles Android builds, lint, existing JVM/reporting tests, ABI checks and release signing. No builds, app execution or tests run locally. Visual contrast, switch gestures, package permissions and installer-return refresh still need physical-device checks.
