# BreakDash v1.0.6

Stronger report privacy, USB diagnostics, and Home navigation fixes.

## Report privacy

- Masks additional vendor-specific identifiers, Bluetooth names/addresses and PINs, activation/registration codes, storage identifiers, and location fields.
- Recognizes common IP, MAC, coordinate, email, URL, and credential-value formats under unexpected field names.
- Parses multiline system properties as complete records, so masked property continuation lines are also hidden.
- Applies a final text pass to uploaded system captures. Optional user notes remain exactly as entered; inspect the preview before sending.
- Raw system inspection remains local and explicitly available.

## USB diagnostics

- Reports Android-visible USB devices with VID/PID, manufacturer/product, class/protocol, interfaces, and endpoints.
- Includes accessory-mode descriptors, removable volume state, and bounded kernel USB descriptor reads when firmware permits.
- Does not open devices, read their contents, request USB access, or collect USB serials. Uploaded removable volume labels/UUIDs are omitted.
- Previous reports had USB settings rather than a connected-device inventory; they cannot reliably identify a device attached at that time. Capture a new report with the device connected.

## Home and app navigation

- Launches external apps into their own tasks, including the explicit NWD Radio fallback. This fixes a path where radio could occupy the launcher task and remain visible when Home was pressed.
- Separates Home and app-launcher intent filters, resets the Home task on launch, and closes dashboard panels when a new Home/launcher intent arrives.
- Back at the dashboard now stays there instead of opening Settings. The stock radio's own Back behavior is controlled by that app; use Home to leave it playing.
- Settings → Device shows whether Android currently prefers BreakDash as Home.
- Reports include Android's preferred Home, BreakDash task/base/top activities, and a small in-memory launch/lifecycle trace, without intent extras or URLs.

## Downloads and validation

- **32-bit ARM (armeabi-v7a):** `BreakDash-v1.0.6-armeabi-v7a.apk`.
- **64-bit ARM (arm64-v8a):** `BreakDash-v1.0.6-arm64-v8a.apk`.

Update through **Updates → Check again**, or install the matching signed APK over the current release to retain preferences. Test Home from the stock Radio and send a fresh report with the USB device connected. If Home still stays on radio, reproduce it immediately before sending so the navigation trace can distinguish launcher/task behavior from firmware button routing.

GitHub Actions runs builds, lint, privacy regression tests, existing reporting/encryption tests, and ABI/signature checks. Vendor Home routing, live USB visibility, and radio audio behavior require head-unit verification. No app builds, execution, or tests run locally.
