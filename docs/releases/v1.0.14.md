# BreakDash v1.0.14

More focused Bluetooth diagnostics for the head unit's scan-start failure.

- Factory inspection now prioritizes Bluetooth/BT-phone/GOCSDK classes across factory namespaces, including public API signatures outside `com.nwd.*`. Unrelated CAN/settings classes cannot fill the selection budget. Each package has its own bounded share of inspection time and report space.
- Adds **Capture Android Bluetooth status**, plus a separate optional **Capture status through local ADB** action when Android denies ordinary access. The ADB action uses the existing private key/authorization flow and one fixed read-only service query. It does not enable debugging, reset Bluetooth or change settings.
- Raw Bluetooth-manager dumps are never displayed, saved or uploaded. A strict projection retains recognized manager state, counts, known profiles and BreakDash/MAXOBD registrations, omitting names, addresses, history, other packages and unknown output.
- Reports retain separate last Classic and BLE scan summaries. Android 12+ permissions are shown as not applicable on Android 10/11. BLE error 3 now clearly identifies an Android scan-start error rather than a failed OBD connection.
- Closing, covering, changing sections or clearing history cancels diagnostic work; attached ADB connections close. Existing finite scans, BLE probe, factory apps, maps and radio remain available.

After updating, run **Scan Classic** and **Scan BLE**, then open **Diagnostics**. Run **Inspect factory Bluetooth interfaces** and **Capture Android Bluetooth status**. If ordinary capture is denied and TCP debugging is available, use **Local ADB setup / authorization**, return, and explicitly run **Capture status through local ADB**. BreakDash cannot activate TCP debugging itself. Finally use **Send feedback** to preview and upload the evidence, including denied/unavailable outcomes.

This update gathers evidence; it does not claim to repair the Bluetooth stack or provide live OBD readings. Install **BreakDash-v1.0.14-armeabi-v7a.apk** on the head unit, or **BreakDash-v1.0.14-arm64-v8a.apk** on compatible 64-bit devices. **Updates → Check again** installs the signed update while retaining preferences.

GitHub Actions runs selection/privacy/state regressions, existing map/JVM/reporting checks, Android lint, both ARM builds and signing verification. No local builds or tests run. Physical head-unit checks are still required for vendor interface visibility, native status access and Bluetooth behavior.
