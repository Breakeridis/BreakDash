# BreakDash v1.0.12

Clearer driving maps with Bright by day and a near-black Dark style at night.

- Stronger road edges, 20% larger street names, and 20% wider roads and casings from zoom 14. Day retains distinct road colours; night uses light local roads and amber major roads, with the blue navigation route remaining prominent.
- Preserves road hierarchy, bridges, tunnels, junctions, road shields and town names. Buildings stay flat and subdued.
- Shows fuel and car-parking icons from zoom 15, with names from zoom 16. Other business and transit markers are hidden; label collision detection stays enabled.
- Adds optional day/night style overrides and **Settings → Maps → Use recommended maps**. Old default styles migrate automatically; other custom HTTPS styles keep their own appearance. Reset clears only the two style overrides, retaining online-map consent, navigation, search and router settings.
- Retains route progress, destination, measured vehicle position, heading and camera ownership across theme changes. Outdated style-load completions are discarded before restoring overlays.
- Keeps the circular map, gestures, heading follow, 45-degree navigation view, smooth vehicle movement, visible-dashboard lifecycle and 20 FPS limit.
- Includes upstream style licences and attribution under **Credits**. Styles are bundled, but tiles, fonts and icons still require internet through OpenFreeMap; this does not add offline maps.

Install **BreakDash-v1.0.12-armeabi-v7a.apk** on the head unit, or **BreakDash-v1.0.12-arm64-v8a.apk** on compatible 64-bit devices. Use **Updates → Check again**, or install the matching signed APK over the current release to retain preferences. Head units still blocked by a pre-v1.0.8 **Missing APK signature** error need one manual installation over the app.

GitHub Actions runs MapLibre style validation, road/label/POI checks, default/custom URL selection tests, existing JVM/reporting tests, Android lint/builds, native-architecture checks and release-signature verification. No local app builds or tests run. Glare readability, rapid theme switching during navigation and rendering performance still need physical head-unit checks; see the [device acceptance checklist](https://github.com/Breakeridis/BreakDash/blob/v1.0.12/docs/driving-maps.md#verification).
