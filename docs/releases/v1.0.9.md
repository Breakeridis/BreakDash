# BreakDash v1.0.9

Smooth vehicle-marker movement synchronized with the map camera.

- Fixes the mismatch where a GPS fix jumped the vehicle dot/arrow forward instantly while the map camera eased toward it over 700 ms, causing the pointer to drift backward and jump forward at each update.
- Moves the marker and follow camera on one finite 700 ms visual timeline, capped at 20 updates per second, including bearing changes. Heading wraps through north along the short path.
- Incoming fixes continue from the current displayed position rather than restarting at an older GPS point. First fixes, gaps over five seconds and jumps over 250 m are placed immediately to avoid animating across unrelated locations.
- Smooths the vehicle marker while exploring too, without taking camera control from touch gestures. Recenter, the 45° navigation angle, lower vehicle position and route overview remain available.
- Stops animation when the cockpit is hidden, GPS is disabled, or the map is destroyed. Frames stop at the latest measured fix; no position extrapolation or additional GPS polling is introduced.
- Keeps raw GPS fixes as the source for speed, accuracy, search, routes and guidance. Visual interpolation does not change those calculations.

Use **BreakDash-v1.0.9-armeabi-v7a.apk** for the head unit, or **BreakDash-v1.0.9-arm64-v8a.apk** for compatible 64-bit devices. Update normally from v1.0.8. A head unit still blocked on an older version's **Missing APK signature** error needs a one-time manual installation of this APK over the existing app to preserve preferences.

GitHub Actions runs Android builds, lint, motion/heading/tracking regressions, existing JVM/reporting tests and APK ABI/signature checks. No local builds, tests, emulators or app execution are used. Check perceived smoothness and frame cost on the head unit while driving, turning, exploring, recentering, stopping and losing GPS.
