# BreakDash v1.0.10

Restores radio-widget connection and station reads while guarding the receiver crash found in feedback.

- Catches malformed/unknown Parcelable broadcast data instead of letting it restart the launcher.
- Reads current frequency/band through the installed factory radio's real generated service/model classes; no vendor Parcel layout is guessed. Only read-only factory-system APK code is accepted.
- Reconnects and reads station/RT status while the cockpit is visible, without sending the frequency-request broadcast. Opening panels or other apps releases the connection and leaves playback running. There is no continuous polling.
- Shows Connecting, Connected/On air, or Radio offline, with a refresh button beside the RADIO shortcut. Previous/next labels are clearer.
- Keeps a valid current station/band when vendor settings omit those keys, so holding a preset can save it. Empty slots remain empty until saved; stock preset banks are not guessed or imported.
- Adds bounded model and broadcast names/types and ignored-payload counters to previewed feedback. Model object values and arbitrary extra contents are not dumped.

Install **BreakDash-v1.0.10-armeabi-v7a.apk** on the head unit, or **BreakDash-v1.0.10-arm64-v8a.apk** on compatible 64-bit devices. Signed updates preserve preferences. Older head-unit updaters blocked by **Missing APK signature** still need a one-time manual APK installation over the app.

After updating, tune a station in Radio and return Home. Check connection/frequency, try Prev and Next, hold a preset to save and tap to recall, then test Home again. If station data is still unavailable, send fresh feedback so the actual factory model schema can be checked. The adapter is conservative about unknown models or updated factory packages outside read-only partitions; these remain usable through the stock Radio app.

GitHub Actions runs builds, lint, synthetic model/trust regressions and existing JVM/reporting/motion/signer checks, followed by ABI and signing verification. Hardware behavior still needs the head-unit check. Nothing is built or run locally.
